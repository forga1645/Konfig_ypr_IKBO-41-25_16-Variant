# Эмулятор оболочки ОС (Вариант №16)

Учебная практическая работа по дисциплине **«Конфигурационное управление»**.

- **Вариант:** №16
- **Группа:** ИКБО-41-25
- **Язык реализации:** Python 3.10+
- **Текущий этап:** Этап 3 — Виртуальная файловая система (VFS)

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС.
На текущем этапе реализована виртуальная файловая система (VFS). Эмулятор загружает структуру директории с диска в память и работает с ней. Оригинальная папка на диске не изменяется.

## 2. Функции и настройки

### 2.1. Команды (работа с VFS)
- `ls [path]` — показать содержимое директории (по умолчанию — текущей).
- `cd [path]` — сменить текущую директорию (по умолчанию — в корень `/`).
- `exit` — завершает работу.

### 2.2. Параметры командной строки
- `--vfs <path>` — путь к директории, из которой загружается VFS.
- `--script <path>` — путь к стартовому скрипту.
- `--config <path>` — путь к конфигурационному файлу TOML.

### 2.3. Конфигурационный файл (TOML)
По умолчанию находится в `configs/default.toml`.
```toml
vfs_path = "tests/data/vfs_minimal"
script_path = "scripts/start.txt"
### 2.4. Приоритет параметров
Важно: по условию варианта №16 значения из TOML-файла перекрывают значения из командной строки.

### 2.5. Виртуальная файловая система (VFS)
Все операции производятся в памяти.

Источник VFS — директория на диске (загружается при старте).

Навигация поддерживает абсолютные и относительные пути, а также . и ...

Приглашение к вводу отображает текущий путь: vfs_minimal:/a/b>.

## 3. Сборка и запуск
Установка зависимостей (для Python 3.10 и ниже):

pip install -r requirements.txt
Запуск с конфигом (рекомендуется):

python -m src.main --config configs/default.toml
Запуск с указанием конкретной VFS:

python -m src.main --vfs tests/data/vfs_deep
Запуск тестов:

pytest tests/ -v

## 4. Примеры использования
$ python -m src.main --vfs tests/data/vfs_deep
