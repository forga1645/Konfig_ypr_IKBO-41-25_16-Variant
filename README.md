# Эмулятор оболочки ОС (Вариант №16)

Учебная практическая работа по дисциплине **«Конфигурационное управление»**.

- **Вариант:** №16
- **Группа:** ИКБО-41-25
- **Язык реализации:** Python 3.10+
- **Текущий этап:** Этап 2 — Конфигурация

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС.
На текущем этапе реализована поддержка CLI-параметров, конфигурационного файла TOML, а также выполнение стартового скрипта. Эмулятор научился принимать настройки при запуске.

## 2. Функции и настройки

### 2.1. Команды (заглушки)
- `ls` — выводит переданные аргументы.
- `cd` — выводит переданные аргументы.
- `exit` — завершает работу.

### 2.2. Параметры командной строки
- `--vfs <path>` — путь к физическому расположению VFS.
- `--script <path>` — путь к стартовому скрипту.
- `--config <path>` — путь к конфигурационному файлу TOML.

### 2.3. Конфигурационный файл (TOML)
По умолчанию находится в `configs/default.toml`.
```toml
vfs_path = "tests/data/vfs_minimal"
script_path = "scripts/start.txt"

### 2.4. Приоритет параметров
Важно: по условию варианта №16 значения из TOML-файла перекрывают значения из командной строки.

### 2.5. Стартовый скрипт
При запуске эмулятор может выполнить список команд из файла (например, scripts/start.txt).

Ошибочные команды не останавливают выполнение, а пропускаются.

На экране отображается ввод и вывод (имитация диалога).

### 3. Сборка и запуск
Установка зависимостей (для Python 3.10 и ниже):

pip install -r requirements.txt
Запуск с конфигом (рекомендуется):

python -m src.main --config configs/default.toml
Запуск с параметрами командной строки:

python -m src.main --vfs tests/data/vfs_minimal --script scripts/start.txt
Запуск тестов:

pytest tests/ -v
