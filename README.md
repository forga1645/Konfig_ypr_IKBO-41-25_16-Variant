# Эмулятор оболочки ОС (Вариант №16)

Учебная практическая работа по дисциплине **«Конфигурационное управление»**.

- **Вариант:** №16
- **Группа:** ИКБО-41-25
- **Язык реализации:** Python 3.10+
- **Текущий этап:** Этап 5 — Дополнительные команды (Проект завершен)

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС.
Проект включает в себя полную реализацию виртуальной файловой системы (VFS) в памяти, конфигурацию через TOML-файлы и CLI, а также полный набор основных и дополнительных команд для работы с файлами и папками.

## 2. Функции и настройки

### 2.1. Команды
- `ls [path]` — показать содержимое директории.
- `cd [path]` — сменить текущую директорию.
- `exit` — завершает работу.
- `uptime` — показать время работы эмулятора.
- `wc <file>` — подсчитать строки, слова и символы в файле.
- `du [path]` — показать размер файла или папки.
- `touch <file>` — создать пустой файл.
- `cp <src> <dst>` — скопировать файл или папку (рекурсивно).
- `vfs-load <path>` — загрузить новую VFS с диска (заменяет текущую).

### 2.2. Параметры командной строки
- `--vfs <path>` — путь к директории, из которой загружается VFS.
- `--script <path>` — путь к стартовому скрипту.
- `--config <path>` — путь к конфигурационному файлу TOML.

### 2.3. Конфигурационный файл (TOML)
По умолчанию находится в `configs/default.toml`.
```toml
vfs_path = "tests/data/vfs_minimal"
script_path = "scripts/start.txt"
Важно: значения из TOML-файла перекрывают значения из командной строки.

### 2.4. Особенности работы VFS
Все изменения (touch, cp) производятся только в памяти.

Оригинальная папка на диске не изменяется.

vfs-load загружает новую VFS атомарно: если загрузка не удалась, старая VFS остается нетронутой.

cp не перезаписывает существующие файлы и защищает от копирования папки в саму себя.

## 3. Сборка и запуск
Установка зависимостей (для Python 3.10 и ниже):

pip install -r requirements.txt
Запуск с конфигом:

python -m src.main --config configs/default.toml
Запуск тестов:

pytest tests/ -v

## 4. Примеры использования

$ python -m src.main --config configs/default.toml
vfs_minimal:/ > touch newfile.txt
vfs_minimal:/ > cp newfile.txt copy.txt
vfs_minimal:/ > ls
copy.txt  newfile.txt  readme.txt
vfs_minimal:/ > vfs-load tests/data/vfs_deep
VFS loaded: vfs_deep
vfs_deep:/ > exit
Bye!

### 4.1. Обработка ошибок

vfs_minimal:/ > cp readme.txt newfile.txt
Error: already exists: newfile.txt
vfs_minimal:/ > cp docs docs/inner
Error: cannot copy directory into itself: docs/inner
