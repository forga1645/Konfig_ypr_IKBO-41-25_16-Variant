## 1. Общее описание

Эмулятор командной строки UNIX-подобной операционной системы.
Программа имитирует работу оболочки ОС: принимает текстовые команды
от пользователя, разбирает их на имя команды и аргументы,
выполняет и выводит результат.

На текущем этапе реализован **минимальный прототип** — REPL-цикл
(Read-Eval-Print Loop) с командами-заглушками `ls` и `cd`,
а также командой выхода `exit`. Реальная виртуальная файловая
система (VFS) будет подключена на следующих этапах.

**Что реализовано на этапе 1:**

- Интерактивный диалог с пользователем в консоли.
- Приглашение к вводу, содержащее имя VFS.
- Простой парсер: разделение строки на команду и аргументы
  по пробелам.
- Обработка ошибок: неизвестная команда, пустой ввод.
- Команды-заглушки `ls` и `cd`, выводящие своё имя и аргументы.
- Команда `exit` для завершения работы.

## 2. Функции и настройки

### 2.1. Команды

| Команда | Аргументы | Описание |
|---|---|---|
| `ls` | `[args...]` | Заглушка. Выводит имя команды и переданные аргументы. |
| `cd` | `[args...]` | Заглушка. Выводит имя команды и переданные аргументы. |
| `exit` | — | Завершить работу эмулятора. |

### 2.2. Параметры командной строки

| Параметр | Обязателен | По умолчанию | Описание |
|---|---|---|---|
| `<vfs_name>` | Нет | `my_vfs` | Имя VFS. Отображается в приглашении к вводу. |

На этапе 1 параметр передаётся как **позиционный аргумент**.
На этапе 2 он будет заменён на именованные флаги
(`--vfs`, `--script`, `--config`) и дополнен чтением из TOML-файла.

### 2.3. Формат приглашения
<имя_VFS>>

text

Пример:
my_vfs>
test_vfs>

text

### 2.4. Формат вывода команд-заглушек
ls: [<аргументы>]
cd: [<аргументы>]

text

Пример:
my_vfs> ls -la /home
ls: ['-la', '/home']
my_vfs> cd /tmp
cd: ['/tmp']

text

### 2.5. Обработка ошибок

| Ситуация | Сообщение |
|---|---|
| Неизвестная команда | `Error: unknown command: '<имя>'` |
| Пустая строка | ничего не выводится, приглашение повторяется |
| Ctrl+D (EOF) | `Bye!` и завершение работы |
