# Эмулятор оболочки ОС (Вариант №16)

Учебная практическая работа по дисциплине **«Конфигурационное управление»**.

- **Вариант:** №16
- **Группа:** ИКБО-41-25
- **Язык реализации:** Python 3.10+
- **Текущий этап:** Этап 4 — Основные команды

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС.
На текущем этапе реализована виртуальная файловая система (VFS) и добавлены основные команды для работы с ней, имитирующие работу в UNIX-подобной командной строке.

## 2. Функции и настройки

### 2.1. Команды
- `ls [path]` — показать содержимое директории.
- `cd [path]` — сменить текущую директорию.
- `exit` — завершает работу.
- `uptime` — показать время работы эмулятора с момента запуска.
- `wc <file>` — подсчитать количество строк, слов и символов в файле.
- `du [path]` — показать размер файла или папки в байтах (рекурсивно).

### 2.2. Параметры командной строки
- `--vfs <path>` — путь к директории, из которой загружается VFS.
- `--script <path>` — путь к стартовому скрипту.
- `--config <path>` — путь к конфигурационному файлу TOML.

### 2.3. Конфигурационный файл (TOML)
По умолчанию находится в `configs/default.toml`.
```toml
vfs_path = "tests/data/vfs_minimal"
script_path = "scripts/start.txt"
Важно: значения из TOML-файла перекрывают значения из командной строки (особенность варианта №16).

### 2.4. Виртуальная файловая система (VFS)
Все операции производятся в памяти.

Источник VFS — директория на диске.

Приглашение к вводу отображает текущий путь: vfs_minimal:/a/b>.

## 3. Сборка и запуск
Установка зависимостей (для Python 3.10 и ниже):

pip install -r requirements.txt
Запуск с конфигом:

python -m src.main --config configs/default.toml
Запуск тестов:

pytest tests/ -v

## 4. Примеры использования
$ python -m src.main --config configs/default.toml
